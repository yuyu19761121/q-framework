## 1. 核心研究問題

一張 GPU 的實體顯示記憶體容量，不一定等於它可以在特定軟體架構下完成的 AI 工作負載上限。HAVEFUN 研究如何提升**有限 VRAM 硬體的任務可完成性**，並在多個不同計算節點之間協同處理可拆分的工作。這不代表 GPU 的原始算力、顯存容量或記憶體頻寬被物理改變。

Q-Framework 以 QmRNA、QVRAM、QSTATIC 等技術家族研究低記憶體執行與計算狀態延續；Temporal Möbius 則以工作結果和資源條件評估候選運算路線。公開文件僅描述功能目標與已驗證現象，**不揭露實現這些功能的專有方法**。

## 2. 第一條證據：單張 RTX 2080 Ti 已實際完成 H3 運算

**顯卡條件：**RTX 2080 Ti，記憶體擴充版，單張約 22 GB（非原廠 11 GB 配置）。

- **Studio #370 與 #371：**單張 GPU 完成 MiniMax H3 原生短片生成，取得可解碼 MP4。這兩次是短片工作負載，並不是 15 秒單次採樣。
- **Job #365：**單張 GPU 依序完成十個短時間生成區塊，後續組裝為 **15 秒、360 幀**影片，總耗時 **3 小時 12 分 08 秒**。過程發生 **9 次 CUDA OOM**，部分區塊重新提交後完成。這證明單卡的**分段產線可完成性**，不等於「沒有任何 OOM」或「單次原生 15 秒採樣成功」。
- **單卡 1080p：**研究負責人已回報成功成果；公開證據仍待對應原生工作收據、實際模型採樣解析度和成品規格核對。此項是「已回報、待驗證」，不能誤寫成未來才要開始的目標，也不能宣稱已獨立完成原生 1080p 性能驗證。

單卡能力是獨立研究成果，不能以四卡產線的數字替代，也不能把不同解析度或不同長度的任務直接比較速度。

## 3. 第二條證據：同張 GPU 的 QmRNA 對照實驗

在同張擴充 22GB RTX 2080 Ti、相同參考輸入與 Seed、**480×832、36 幀、24fps、10 Steps** 的受控實驗中：

| 路徑 | 觀察 |
|---|---|
| 基準執行路徑 | Step 1 進入 **PRE-OOM** 保護條件，未交付預期的單 Worker MP4 |
| 啟用 QmRNA 保護的路徑 | 完成全部 10 Steps，成功產生 MP4，該輪未記錄 CUDA HARD_OOM |

這支持一項具體技術結論：在已測定條件下，**執行策略的差異改變了工作能否完成**。PRE-OOM 是軟體事前保護事件，不等同硬體已發生 CUDA Out-of-Memory 例外；這項實驗也不能外推為所有模型、所有影片都永久不會 OOM。

**核心實現方法保密。**可供審查的是輸入範圍、結果、比較設計、證據等級與失敗邊界；完整配置、原生接入細節、控制策略和底層收據不公開。

## 4. 第三條證據：四 GPU 叢集實際交付效率

正式 Job **#361** 使用**四張獨立 22GB RTX 2080 Ti** 執行十個影片生成區塊，配合 CPU 後製，完成：

| 項目 | 已記錄成果 |
|---|---|
| 最終影片時長 | 15.000 秒 |
| 幀數與幀率 | 360 幀／24fps |
| 最終影片畫布 | 480×832（9:16） |
| 實際參與的 GPU | 四張獨立 RTX 2080 Ti 22GB |
| 端到端交付時間 | **14 分 37 秒** |
| 成品驗收 | MP4 可完整解碼，幀數及時長符合該次任務 |

這是**端到端影片工作流**成果，不能當成單張 GPU 的原生採樣速度，更不能與 1080p 的其他測試直接比較。四卡的 VRAM 為**分散的獨立資源**，並非一張可直接定址的 88GB GPU。

## 5. 計算延續、輸出一致性與數學驗證

其他獨立控制實驗包括：

- 跨 GPU 的 20-Step 數值延續與對照結果位元一致，測得最大絕對差異 **0.0**。
- 約 **250 MiB** 計算狀態搬運，來源與目標驗證摘要一致。
- QmRNA 受控 22 幀影片比較，**22／22 個解碼影格一致**。
- Windows 與 Mac 不同設備之間，已有分散數學計算、獨立結果驗算及有限規模模型權重訓練實驗。

每項實驗的條件不同，不得把「受控狀態搬運成功」寫成「所有模型都已具備任意異卡無縫接續」，也不得把局部模型學習寫成真正通用自主 AI 已完成。

## 6. 異質超級電腦神經網絡：最終研究願景

HAVEFUN 期望建立跨 GPU、CPU、不同作業系統與獨立計算設備的智慧運算網絡。研究方向不只包含工作分配，也包括安全的狀態保存、結果驗算、歷史經驗累積及依據觀察結果修正決策。

**已獲得的工程基礎：**單卡 H3 成片、同卡低記憶體對照、四卡影片交付、跨裝置數值一致性，以及特定範圍的數學與模型學習實驗。

**尚待驗證與擴大：**全網持續自主學習、任意異世代 GPU 的通用模型狀態恢復、無人工介入的普適決策能力，以及對 H100/H200 在相同工作負載下的完整效能比較。
