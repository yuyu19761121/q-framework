# Q-Framework | Security and BlackBox Policy

This is a **public research and documentation repository**, not the location of HAVEFUN's private GPU runtime or proprietary QmRNA / QVRAM / Temporal Möbius implementation.

**Never publish:** core source code or implementation patches, native model graphs, private execution settings or tensor states, full diagnostic logs, credentials, access tokens, internal service paths, private Owner prompts, or customer photos/audio/video.

External research evaluation receives approved aggregate claims, measurement limitations and optionally owner-authorized de-identified evidence. Repository collaborators must receive explicit Owner approval before publishing new experimental details.

**Disclosure response:** do not post a suspected secret or private asset in a public GitHub issue. Contact the repository Owner through a separately agreed private channel. Rotate exposed credentials and evaluate public Git history, forks and caches; deleting a current file cannot revoke prior disclosure.

See [BlackBox disclosure policy](docs/blackbox-disclosure-policy.md) and [AI-readable public claim summary](evidence/claims-public-rc4.3.json).
