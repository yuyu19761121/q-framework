# Q-Framework | Public Disclosure Boundary — BlackBox

**Public research claims; private implementation.** The project shares bounded experimental observations and evidence grades to permit meaningful outside review without releasing the underlying proprietary source, native computation hooks, state encodings, customer content, or owner-only media.

| Public | Limited owner-authorized review | Owner-only |
|---|---|---|
| Workload scope, GPU class, outcome and limitations | De-identified, minimum-necessary third-party verification | Source, runtime internals, raw job logs and media, credentials |
| Single-card / multi-card results as separate observations | Revocable independent audit of defined cases | Complete prompts, private checkpoints and production configuration |

**Not all published claims have the same verification status.** An externally published report of successful 1080p single-card work remains marked as Owner-reported pending native sampler and artifact receipt verification. The QmRNA PRE-OOM A/B is a controlled conditional result; the four-card #361 end-to-end delivery is a distinct experiment.

Before any future publication, Owner approval and automatic disclosure checks are required. They reduce risk but cannot automatically retract Git history or cached prior files.
