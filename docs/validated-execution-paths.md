Q-Framework has completed engineering demonstrations involving heterogeneous resources and generative AI workloads.

| Result category | Completed observation |
|---|---|

| Real H3 media | Completed video output after cross-GPU continuation |
| Collaborative production | Four independent GPU workers participating in a **15-second, 540-frame** final output |
| Cross-environment numerics | Matching recomputation-result hashes across three environments |
| QSTATIC + QmRNA visual output | **22/22** decoded frames with matching hashes in a controlled comparison |

These observations reflect their respective measured configurations.
