# Q-Framework｜公開術語概覽

Q-Framework 是面向異構 AI 運算協作與生成式媒體的技術體系。以下提供對外溝通使用的概念性名稱。

| 名稱 | 對外概念 |
|---|---|
| **Q-Framework** | 異構 AI 運算協作及運算延續架構 |
| **QmRNA** | Q-Framework 技術體系中的運算協作概念 |
| **QVRAM** | Q-Framework 技術體系中的運算資源概念 |
| **QSTATIC** | 與生成式媒體參考及視覺協作有關的技術概念 |
| **QSTATE** | 與可驗證運算結果有關的概念 |
| **QAnswer** | 與 AI 工作協調有關的技術概念 |
| **H3** | 本計畫已公開成果中的 AI 影片生成工作負載 |
| **Live Compute** | 運算成果的展示與觀察介面 |

## 技術願景

可能應用涵蓋影像創作、創作者工具、企業工作站、異構算力平台、邊緣 AI 與跨產業技術整合。這些是可並行探索的多元應用可能性。
